## Быстрый старт

1. Установите APK-файл Happwner из [Releases](https://github.com/Omegaplexx/Happwner/releases) — поддерживается Android 5.0 и выше;
2. Вставьте `crypt`-ссылку в поле URL на главном экране, нажмите на ключ;
3. Введите любой HWID, выберите один из встроенных User-Agent, нажмите «Профили» — приложение покажет конфигурации, готовые к переносу в ваш VPN-клиент.

## Возможности

**Happwner** извлекает чистые VPN-конфигурации и передаёт их в любые приложения. Вам <u>не нужно</u> устанавливать Happ, чтобы пользоваться всеми его подписками.

* **Расшифровка ссылок**. Форматы:
  * **Happ**: `crypt`, `crypt2`, `crypt3`, `crypt4`, `crypt5` (old/new)
  * **v2RayTun**: `crypt3`, `crypt4`, `key3`
  * **INCY**: `crypt1`

  Интернет-соединение не требуется;

* **Расшифровка профилей**. Если провайдер зашифровал конфиги одним из десяти ключей `key[01–10]`, встроенных в Happ, приложение автоматически расшифрует их и отобразит соответствующую надпись;
* **Подмена HWID** при запросе подписки в интерфейсе Happwner. Позволяет обойти лимит на число устройств и восстановить доступ к подписке при смене устройства;
* **Конвертация профилей** для большей совместимости с VPN-клиентами. Подробнее — в разделе [ниже](#конвертация-профилей);
* **Мост подписок** — служба обновления Happ-подписок внутри любых приложений (NekoBox, Hiddify, v2rayNG, husi, Exclave, Karing и др.);
* **Перехват интент-ссылок** `happ://add` и аналогичных для v2RayTun и INCY, чтобы ссылки на подписки попадали из браузера сразу в Happwner;

## Конвертация профилей

Happ-провайдеры отдают профили в формате Xray JSON, который понимают не все клиенты. Happwner может "переводить" конфиги в один из трёх форматов:

| Режим | Результат | Для каких клиентов |
| --- | --- | --- |
| **Xray в URI** | ссылки `vless://`, `hy2://`, `trojan://` и др. | подходит почти всем |
| **Xray в sing-box** | JSON-конфиги sing-box | NekoBox, husi, Hiddify, Karing и др. |
| **Xray в Mihomo** | YAML-конфиги Mihomo (Clash Meta) | FlClash, Clash Meta, Prizrak-Box и др. |

Режим выбирается отдельно для двух случаев:
* **Профили** — для запроса конфигураций в самом Happwner;
* **Подписка** — когда их запрашивает другое приложение через Мост.

Не каждый профиль конвертируется без потерь: часть возможностей Xray не имеет аналогов в других форматах. Неподдерживаемые профили пропускаются, а их число отображается рядом с результатом. Полный список ограничений есть в самом приложении, в описании каждого режима.

## Альтернативные способы расшифровки

Эти способы нужны в редких случаях, когда Happwner не может расшифровать ссылку сам. Все они требуют дополнительных действий с вашей стороны и не гарантируют результат.

### [Happanion](https://github.com/Omegaplexx/Happanion)

Приложение-компаньон, устанавливается **вместо** Happ из Google Play. Умеет расшифровывать `happ://crypt5` с помощью библиотеки из Happ и **принудительно** направлять браузерные интент-ссылки в Happwner. Устанавливается из настроек Happwner, раздел «Расшифровка».

### Xposed

* **Перехват ссылок**. Работает не только в Happ. Полезно, если приложение-цель шифрует/скрывает ссылку, по которой получает профили;
* **Подмена HWID внутри приложений**, отмеченных как целевые в менеджере Xposed;
* **Доступ к профилям `crypt`-подписок**. Только для Happ и v2RayTun. Принудительно отображает параметры профилей и позволяет экспортировать конфиги, даже если подписка зашифрована;
* **Быстрый вызов интерфейса Happwner** тремя одновременными касаниями, когда открыто целевое приложение.

Для работы Xposed-функционала требуется установленный Xposed / EdXposed / LSPosed / Vector ИЛИ пропатченная версия нужного приложения с помощью Xpatch / LSPatch / NPatch / FPA.

#### Установка с Root

1. Установите Happwner и приложение-цель (Happ, v2RayTun, INCY или другое);
2. Включите Happwner в менеджере Xposed, выберите «охват»;
3. Перезапустите Happwner и отмеченные приложения.

#### Установка без Root

1. Установите Happwner, приложение-цель и [NPatch](https://github.com/7723mod/NPatch/releases/tag/v1.0.2) (рекомендуется версия **1.0.2**);
2. В NPatch: *вкладка «Управление»* → *кнопка «+»* → *«Выберите установленное приложение»* → ***ваша цель*** → *«Интегрированный» режим* → *«Встроить модули»* → ***Happwner*** → *«Запустить патч»*.

**NPatch не сообщает об успешной установке пропатченного приложения.** Нажмите «Установить», подождите несколько секунд и проверьте ваше приложение в списке установленных.

## Зачем нужен Happwner?

Чтобы вернуть пользователю контроль над подписками, повысить прозрачность услуг и обезопасить себя от недобросовестных «барыг».

**Happ** — это не только VPN-приложение, но и часть коммерческой экосистемы, ориентированной на VPN-провайдеров. Happ предоставляет им расширенные возможности за счёт введения ограничений для пользователей.

* Шифрование ссылок (`happ://crypt5`) заставляет вас установить Happ, скрывает реальный URL подписки и блокирует просмотр адресов серверов. Вы не узнаете, какому серверу доверяете весь ваш трафик и откуда он был получен. Всё зависит от честности поставщика;
* Идентификатор оборудования (HWID) жёстко привязывает купленную подписку к конкретному устройству;
* Отсутствие гибких настроек в Happ не позволяет скрывать трафик от сомнительных поставщиков с помощью прокси-цепочек;
* Если в `crypt5`-ссылку встроен [ProviderID](https://www.happ.su/main/ru/dev-docs/provider-id), то раз в сутки приложение будет сравнивать хэш домена подписки, свою версию и версию ОС с теми данными, что указаны в личном кабинете продавца на [happ-proxy.com](https://happ-proxy.com);
* Продавец, добавивший **ProviderID** в зашифрованную ссылку, получает возможность [удалённо управлять приложением](https://www.happ.su/main/ru/dev-docs/app-management) без участия пользователя — принудительно отправлять HWID, подменять URL подписки, отключать авторизацию прокси и т.д.:

<summary>Возможности ProviderID</summary>

* Принудительно включать отправку HWID, даже если отправка отключена в настройках;
* Блокировать ручное изменение User-Agent, сохраняя возможность менять этот заголовок удалённо;
* Управлять локальными SOCKS- и HTTP-прокси: перенастраивать авторизацию или отключать её;
* Принудительно подключать пользователя к определённому серверу при запуске Happ;
* Отключать глобальную маршрутизацию в Happ;
* Настраивать проксирование приложений (добавлять/удалять исключения);
* Скрывать VPN-серверы в зависимости от типа подключения (Wi-Fi / моб. интернет);
* Настраивать автотестирование серверов (автопинг) при открытии приложения;
* Управлять типом `ping` (`via Proxy - GET/HEAD`, `TCP`, `ICMP`) и настраивать свой URL для проверки доступности серверов;
* Менять URL подписки;
* Задавать интервал автообновления подписки;
* Включать автозапуск Happ при включении устройства;
* Принудительно обновлять все подписки при каждом запуске приложения;
* Разворачивать список серверов при обновлении подписки или полностью отключать сворачивание списка;
* Закреплять или откреплять подписку в общем списке;
* Изменять сортировку серверов в списке по алфавиту или пингу;
* Управлять мультиплексированием трафика.

**Список неполный.** Параметры управления передаются через HTTP-заголовки и тело ответа при каждом обновлении подписки.
